WhatsApp WeChat Messaging Bridge

A third-party dashboard that connects WhatsApp and WeChat business accounts, so conversations from both apps show up in a single inbox.

Role
Full-stack Developer
Type
Cross-platform messaging dashboard
Live
we-chat-test.vercel.app
Open live site View code on GitHub

Overview

Businesses that talk to customers on both WhatsApp and WeChat usually end up juggling two separate apps, two separate logins, and two separate habits. This platform merges both into one inbox: every conversation is tagged by where it came from, [WA] or [WC], but read, sent, and searched from the same screen.

Each contact can be renamed inline, individual messages can be deleted, and attachments such as documents or images are sent the same way whichever platform the conversation started on.

How it fits together

WhatsAppWhatsApp API
WeChatWeChat API
WebhooksIncoming messages from both platforms
ASP.NET Core Web APIC# back end and REST endpoints
React inboxOne list, each chat labelled [WA] or [WC]

Messages from both platforms arrive by webhook and land in one inbox. Replies and attachments go back out through each platform's API.

Screenshots

What I built

  • Unified inbox that merges WhatsApp and WeChat conversations, clearly labelled by source.
  • Per-conversation view with timestamps, inline contact renaming, and per-message delete.
  • File and image attachments sent the same way regardless of which platform the chat is on.
  • Built for support teams who'd otherwise need two separate tools open at once.

InstaTags

A Chrome extension and web app that turns a photo into ready-to-use Instagram hashtags, so posting takes less time and less guessing.

Role
Developer
Type
Chrome extension + web app
Live
tagsout.vercel.app
Open live site View code on GitHub

Overview

InstaTags exists to solve one small, repetitive problem: coming up with a good set of hashtags every time you post. Instead of hand-picking tags or copying a generic list, InstaTags looks at the photo itself. Several lightweight AI models each analyze a different signal in the image (subject, style, colour, mood) and their findings are combined into one set of relevant tags.

It's built two ways: as a Chrome extension that plugs directly into the Instagram posting flow, and as a standalone web app for anyone who just wants to drop in an image and copy the results.

How it fits together

Your photoFrom the Instagram post, or dropped into the web app
Image modelsSubject, style, colour and mood, each read separately
One tag listFindings merged, ready to copy into the caption

Screenshots

Using the extension

  1. Create a new post on Instagram and choose the photo or video.
  2. Go through the usual editing steps until you reach the caption screen.
  3. Open the InstaTags extension icon to launch the hashtag generator.
  4. Let it analyze the image. This takes a few seconds.
  5. Review the suggested hashtags.
  6. Copy the tags into your caption and post.

What I built

  • Chrome extension that reads the photo mid-upload and generates matching hashtags inline.
  • Companion web app for tagging an image without installing anything.
  • Multiple models analysing the same image from different angles, merged into one tag list.
  • One-click copy so tags go straight into the caption.

Stack

  • JavaScript
  • Chrome Extension APIs
  • Image recognition models
  • Vercel

Overview

Finding a trustworthy car workshop usually means asking around or scrolling through reviews on a maps app with no idea what's actually available. ServiceHub puts that in one place: nearby workshops with ratings and specialties up front, and a booking flow that takes you from "I need an oil change" to a confirmed time slot without leaving the app.

The booking flow is the core of it. Pick what you need done, pick a date from the calendar, pick an open time slot, add a note for the technician if something specific needs attention, and confirm.

What I built

  • Sign-up and login flow, including Google and Apple sign-in.
  • Workshop discovery with search, filters (nearest, most popular) and ratings.
  • A three-step booking flow: service type, date, then time slot.
  • Optional notes field so a customer can flag something specific before the appointment.
  • Profile screen for vehicle data, saved addresses, payment methods and account settings.

Setrum

A home energy monitoring dashboard: track electricity usage by device and estimate the bill before it arrives.

Role
Frontend Developer
Type
Web dashboard
Status
Finished
View code on GitHub

Overview

Setrum turns raw electricity usage into something a household can actually act on. The home screen shows usage as daily, monthly or annual totals with a trend chart, alongside a live breakdown of what each connected device (air conditioner, TV, PC, lamp, fridge, air fryer) is drawing. From there it's a short step to estimating what the next bill will look like, or catching a device that's about to fail before it does.

Screenshots

What I built

  • Usage dashboard with daily, monthly and annual views and a trend chart.
  • Per-device list showing live draw or usage for the selected period.
  • Bill estimation screen: usage, rate per kWh, tax and stamp combined into a printable summary.
  • Notifications for a device that looks faulty or a detected power outage.
  • Profile section for account details, password, language, notification preferences and connected meters.

Stack

  • HTML
  • CSS
  • JavaScript
  • Git
  • No backend
